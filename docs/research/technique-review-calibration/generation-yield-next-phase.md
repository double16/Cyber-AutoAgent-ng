# Generation-yield pilot after review acceptance

This is a prepared design, not an authorized live run. Freeze a separate protocol and provider
request allowance before execution. A review-only fixture experiment cannot establish generation
yield, and approval rate alone cannot establish useful guidance.

Use one HTTP, one network and one filesystem authoring request with explicit authored obligations,
applicability and restrictions. Do not pass reference drafts or their labels to authors. Freeze
source inputs, model settings, runtime identity and request order before comparing revisions.
Use the normal source-selection, requirement-support, authoring, independent critique and repair
owners, with their existing limits. Keep every rejected or incomplete attempt in the denominator.
Never bypass unsupported research merely to obtain a document, and do not publish experiment output.

First determine which comparison is feasible within an explicit allowance. If sources are frozen
and retained to isolate authoring, call the result yield conditional on those supplied sources;
it is not end-to-end research-and-generation performance. A full-pipeline trial must also include
research retrieval, assessment and recovery in its request count. Do not present either as an
unqualified production reliability estimate from three cases.

Primary outcome: number of complete generated documents that human adjudication finds materially
correct and useful for the requested method, divided by the number of fixed authoring requests.
Review exact output hashes. Record model approval separately so false approvals and false blocks
remain visible. Report research failures, author exhaustion, contract failures, semantic disputes,
independent review failures, provider errors and budget exhaustion as separate dispositions.

Secondary measures: author attempts, each repair owner, provider requests per accepted document,
unsupported claims, policy/outcome confusion, missing requested deliverables and repair regressions.
A document with no confirmed vulnerability can still be useful; this is reusable methodology, not
a target execution result. Human judgments must evaluate concrete procedural contribution and
controls rather than citation count, document length or elaborate commands.

A matched baseline comparison is required before claiming improved yield. Preserve the baseline
revision and freeze equal inputs and allowances; alternate order, retain failed attempts and use
no outcome-driven fixture replacement. A candidate-only pilot can establish observed outcomes,
not comparative improvement. Further cases and repetitions are needed for generalization.
