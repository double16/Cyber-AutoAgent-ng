# Next intervention before another live trial

Preserve the failed run and stop live calls before changing the review contract. The remaining
problem is semantic scope, not ID availability or exact excerpt matching.

Clarify the shared frozen criteria and role guidance at their source:

- Technical support concerns asserted factual mechanisms. A finding should identify the exact
  unsupported assertion and explain why it is a fact asserted by the document, rather than a
  declared prerequisite to establish later or an original control derived from supported facts.
  Original synthesis does not exempt unsupported assertions, and lack of a matching source
  workflow does not alone establish a defect.
- Operational objections must identify an advertised conclusion that the existing method cannot
  support. Do not demand an authorization conclusion from a control explicitly limited to request
  shape, or treat an inconclusive branch as a false finding.
- Attribution findings must identify a materially false claim or misleading omission against the
  supplied requirement. Accurate source scope in metadata counts. Require body placement only if
  an actual deliverable or policy says so; optional elaboration belongs in suggestions.

Keep semantic classification with the model. Python should validate references and complete
structured findings without deciding from keywords whether a claim is supported. Keep every
assessment independent and retain the shared single correction allowance.

Offline regressions should cover both supported original synthesis and actual unsupported factual
assertions across HTTP, network and filesystem work. Include conditional prerequisites, a source
that contributes a relevant fact but no full workflow, an irrelevant source, explicit inconclusive
controls, misleading attribution, accurate metadata attribution, and a real body-placement request.
Review native/tool schemas and complete investigation, finalization and correction inputs.

After implementation and offline checks, freeze another revision and obtain a fresh bounded live
allowance. Reuse unchanged human-labeled inputs; do not edit the corrected HTTP fixture merely to
satisfy the observed reviewer objections. A source-richer variant could test source-context effects,
but it must be a separate input with its own adjudication and cannot replace this failed case.

results. Approval counts and successful reference validation remain insufficient measures of useful
technique generation.
