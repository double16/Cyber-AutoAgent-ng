## Outcomes and final role-scope correction

The frozen schedule completed 26 provider chat calls across 18 role invocations. None of its 12
cases established acceptance. Five returned substantive source/critique assessments; three author
or draft cases failed missing controller-owned source metadata; two hypothesis cases failed the
generic review-status contract; two feedback cases failed because the harness supplied a dictionary
where persisted use_context requires JSON text. The fixture mistakes belong to this replay harness,
not the production agents. Their failures are retained and must not be counted as model decisions.
The hypothesis checks used the generic output model rather than the full publication-bound runtime
contract and cannot establish end-to-end closure correctness. The source checks exercised the initial
assessment, not the existing independent coverage-reclassification stage.

The critic rejected focused header, network and filesystem procedures using additional completeness
requirements. Inspection showed author enrichment guidance entering research, critique and assessor
inputs. After the frozen run finished, that guidance was separated: only authors receive enrichment
preferences; other roles receive shared interpretation rules and actual supplied obligations.
Critic control summaries may paraphrase actual steps with references; only assessor discriminator
quotations require verbatim draft text. Regression tests exercise author correction as well as
research, request review, critic and assessor input construction.

One separate smoke test reused the exact network control with the final scope correction. The
critic approved it, but the assessor disagreed using a NAT/identity-mapping scenario and requested
correction. Whether that scenario satisfies the explicit independently-established-denial prerequisite
remains disputed. The next provider request was blocked by the cumulative cap. This is an unresolved
smoke result, not an approved document or a replacement for the failed frozen trial.

Total: **30 provider chat requests**, sequential, and **21 role invocations**, including the
budget-blocked correction. No further model calls are authorized by this trial. No useful-document
yield improvement or production acceptance has been demonstrated. Keep publication and feedback
guards enabled; do not recommend another production run on this evidence alone.

The original neutral decision's stored delivery and task context were captured separately through
read-only SQLite after a successful integrity check. Historical scores are explicitly not expected
outcomes; original tool outcomes remain unknown where not retained. That captured case was not
re-evaluated within the call cap. A Langfuse lookup returned a tool error and did not recover the
missing assembled document. Exact corrected production drafts remain unaccepted.
