# Selection intent and evaluator repair ownership

The hypothesis phase objective no longer adds payloads and checklists to methodology requests.
Authors still receive these preferences through authoring guidance. Direct lookup retains the
original request; phase alignment remains context. Bundle planning and review distinguish phase
framing from mandatory deliverables.

The workflow validates canonical hypothesis feedback before persisting actionable reviews.
Invalid evaluator fallbacks are recorded as evaluator failures with no executor repair, leaving
unchanged publications eligible for later evaluation. Existing correction preserves valid subject
assessments. Structured semantic judgments remain model-owned.

Native finalization allows completing assessments from already inspected content and receipts.
Shared interpretation explicitly allows client input and data flow to ground conditional proposals
without confirmed server handling. No tool fields, procedure identities or migrations were added.

lookup, document selection, shared interpretation, hypothesis review, native finalization,
